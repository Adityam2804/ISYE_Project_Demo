# ISYE 2530 — Student Project Journey Demo

Interactive Streamlit walkthrough of the course project across M1–M4.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Three example datasets

The `datasets/` folder contains one small example for each project track:

- `supply_chain_orders.csv`
- `healthcare_service_requests.csv`
- `humanitarian_requests.csv`

In M1, the student chooses and inspects a dataset **before** defining the decision-maker, recurring decision(s), objective, and evidence. That selection then drives the M2 cleaning/SQL context and the M3/M4 decision-support language.
